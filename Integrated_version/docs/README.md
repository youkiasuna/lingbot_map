# 文件模組

此目錄保留跨模組的系統契約與長篇流程說明。單一模組的快速入口和命令放在該模組的 `README.md`；已完成/未驗證的研究結論見根目錄 `PROJECT_RESULT_AUDIT.md`。

- `NAVIGATION_RUNTIME_CONTRACT.md`：姿態、路徑、控制狀態 JSON 欄位和座標慣例。
- `LIVE_MAPPING_ARCHITECTURE.md`：runtime 狀態機、地圖發布及目前限制。
- `LIVE_MAPPING_REPLAY.md`：prediction replay 和 LingBot backend 操作流程。
- `LIVE_POINTCLOUD_MAPPING_ONLY.md`：只建圖 runtime。
- `ONLINE_RTSP_WORKFLOW.md`：相機串流工作流程。

文件中的命令需與對應模組 README 一起維護；不得把架構草案描述成已驗證的實車能力。
